# Folio

프로젝트의 기록을 남기는 개발자 워크스페이스.

## Pages

- 일지 (Journal): 날짜별 업무 일지, 태그, 자동 저장
- 문서 (Docs): 공통 문서, 카테고리, 검색, 마크다운 프리뷰
- 일정 (Board): 칸반 (Backlog, In Progress, Review, Done)

## 스택

- Next.js 16 + React 19
- Tailwind v4 + shadcn/ui
- localStorage 기반 로컬 저장

## 시작

```bash
npm run dev
# http://localhost:3000
```
