## 일지 (Journal)

날짜별 업무 기록. 진입 시 기본 탭입니다.

### 날짜 이동
- 에디터 상단 `‹ 날짜 ›` 로 하루씩 이동
- 날짜를 바꾸기 전에 현재 초안은 자동으로 반영·저장됩니다

### 자동 저장 · 수동 저장
- 입력 후 잠시 두면 자동 저장
- **저장** 버튼으로 즉시 저장 (상태: 저장 중 / 저장됨 / 실패)
- 실패 시 **다시 시도**가 표시됩니다

### 태그
- 하단 입력란에 입력 후 Enter 또는 쉼표
- 배지 클릭으로 제거
- 기존 태그 자동완성·클릭 추가
- 태그 클라우드/필터는 비 writing-first 레이아웃 또는 통계에서 활용

### Obsidian 가져오기
- **Obsidian 가져오기**로 `.md` 파일(복수) 선택
- 파일명·프론트매터의 날짜를 인식해 항상 새 일지로 추가
- 원본 지문이 같은 파일은 중복 수집하지 않습니다
- 상세: [GETTING-STARTED.md](./GETTING-STARTED.md)

### 통계
- 일지 탭 안 **통계** 서브탭
- 작성 일수·태그 빈도 등 차트 확인

### 내보내기
- **내보내기** 메뉴: 기간 Markdown / 오늘 Markdown

## 문서 (Docs)

팀·개인 공통 문서와 지식 링크.

### 마크다운 편집
- **새 문서** → 제목(필수) · 본문 · 카테고리
- 읽기 모드: 마크다운 프리뷰
- 편집 모드: **편집 / 미리보기 / 분할**

### 분할 프리뷰
- **분할**에서 왼쪽 편집 · 오른쪽 실시간 프리뷰

### 카테고리
- 저장 시 카테고리 선택
- 목록 상단 배지로 필터

### `[[링크]]` 그래프
- 본문에 `[[문서 제목]]` 또는 `[[문서 제목|별칭]]`
- `[[` 입력 시 자동완성
- 하단(또는 우측) **링크 그래프**: 노드 클릭 → 문서 이동
- 엣지가 없으면 노드만 표시됩니다 (링크를 추가하면 연결선이 생김)

### 역링크
- 다른 문서가 나를 `[[…]]` 로 가리키면 하단에 **역링크** 목록

### Obsidian · 내보내기
- **수집함**에서 Obsidian 볼트/Markdown을 미리 분석한 뒤 가져오기
- `source` · `type` · `created` · `tags`를 보존하고 log는 일지, 나머지는 문서로 분류
- 기존 항목을 덮어쓰지 않는 append-only 방식과 중복 방지 이력 제공
- 선택 문서 MD / ZIP(필터·전체)

## 일정 (Board)

4컬럼 칸반: Backlog → In Progress → Review → Done

### 칸반 사용법
- 컬럼 **+** 로 태스크 추가
- 제목 · 설명 · 우선순위 · 태그 편집

### DnD
- 카드를 드래그해 다른 컬럼에 놓으면 상태가 바뀝니다
- 드래그 중 오버레이로 미리보기가 표시됩니다

### 키보드 이동
- 카드 포커스 후 좌우 화살표로 컬럼 이동 (접근성 지원)

### Jira 연동
- 환경변수에 Jira 설정 후 **Jira 동기화**
- 카드에 Jira 키·외부 링크 표시
- 상세: [docs/env.example](./env.example)

### 즐겨찾기
- 카드에서 즐겨찾기 토글 → 빠른 접근

### 분석 · 내보내기
- **분석** 서브탭: 상태·처리 시간 등
- Board CSV / JSON 내보내기

## 프로세스 (Beacon)

프로젝트 Gate · Timeline · 산출물.

### Gate 상태
- P0–P4 등 Gate 진행률
- 우측 사이드바 **Gate 상태** 프로그레스와 연동

### Timeline
- 프로젝트 이벤트 타임라인 조회·추가(동의/연동 시)

### 산출물
- 체크리스트·아티팩트 상태 확인
- Docs에서 Beacon으로 export 가능

### Beacon 연동
- 저장 모드 **beacon** 또는 `.beacon` 폴더
- `BEACON_PROJECT_ROOT` 환경변수
- 상세: [BEACON.md](./BEACON.md)

## 검색

### 통합 검색
- 일지 · 문서 · 일정 전체를 한 번에 검색
- 결과 클릭 시 해당 탭·항목으로 이동

### 단축키
- **⌘K** / **Ctrl+K** — 검색 열기
- 헤더 돋보기 아이콘 클릭으로도 확장

### 필터 · 정렬
- 키워드 relevance 순 정렬
- 소스(일지/문서/일정)별 결과 구분

## 저장 모드

사이드바 하단 **저장 모드** 토글.

| 모드 | 저장 위치 | 로그인 | 특징 |
|------|-----------|--------|------|
| **local** | 브라우저 localStorage | 불필요 | 기본 · 오프라인 · 기기 종속 |
| **cloud** | Supabase | 필요 | 멀티 기기 · 팀 공유 |
| **beacon** | `.beacon` 캐시/프로젝트 | 선택 | CLI·Gate와 동기 |

### 전환 방법
1. 사이드바에서 모드 변경
2. 이후 저장/로드는 선택한 모드 우선 (실패 시 폴백)
3. cloud 전환 전 Supabase env·스키마·로그인 확인

## MCP

다른 프로젝트(Cursor) 작업을 Folio에 쌓습니다.

### IDE 연동
```bash
npm run mcp:link -- /path/to/your-project --name my-app
```
- `.cursor/mcp.json` · 자동기록 규칙 설치

### Git webhook
- `POST /api/mcp/git-webhook`
- `FOLIO_MCP_WEBHOOK_SECRET` 설정

### CLI
```bash
npm run mcp:client -- tools
npm run mcp:client -- call journal_read '{}'
```

### UI 동기화
- Folio에서 **MCP 가져오기** → 일지/문서/일정 반영

상세: [MCP-GUIDE.md](./MCP-GUIDE.md) · [MCP.md](./MCP.md)
