# Getting started

```bash
git clone https://github.com/dayainow/folio.git
cd folio
npm install
npm run dev
```

Open http://localhost:3000

Env: copy `docs/env.example` → `.env.local`

Quality:

```bash
npm run lint && npm run typecheck && npm run test && npm run qa:smoke
```

Language: header toggle · default Korean · browser detection for en/ja.
