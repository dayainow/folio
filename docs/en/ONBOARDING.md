# Folio Onboarding — First 10 minutes

Get started with Folio in about **10 minutes**.

> Screenshot placeholders: `(Screenshot: …)` can be replaced later.

---

## Before you start

- Node.js 20+
- Clone the Folio repository

```bash
cd /path/to/folio
npm install
npm run dev
```

Open `http://localhost:3000`.

---

## Step 1 — Open Folio

1. Visit `http://localhost:3000`
2. You should see the **Folio** logo and tabs (**Journal / Docs / Board / Process**)
3. **Journal** opens by default (writing-first layout)

**Tip:** On mobile, use the bottom tab bar. Open the summary panel from the header.

---

## Step 2 — Language

Use the header language toggle (**ko / en / ja**). Folio detects the browser language and falls back to Korean.

---

## Step 3 — Save mode

1. Open the **Summary** sidebar
2. Choose storage mode: local / cloud / Beacon
