# Folio i18n (P53)

브라우저 클라이언트 i18n (next-intl 미사용 · 경량 자체 구현).

## 지원 언어

| 코드 | 언어 | 기본 |
|------|------|------|
| `ko` | 한국어 | ✅ |
| `en` | English | |
| `ja` | 日本語 | |

## API

- `src/lib/i18n.ts` — `t` / `resolveLocale` / `setLocale` / `detectBrowserLocale`
- `src/locales/{ko,en,ja}.json` — UI 카탈로그
- `useI18n()` — React 훅 (`I18nProvider`)
- 헤더 **LanguageToggle** — ko↔en↔ja

우선순위: **저장(`folio_locale`)** → **브라우저 Accept-Language** → **ko**
