수동 체크리스트: [a11y-checklist.md](./a11y-checklist.md)

## v2.0 최종 점검 (수동)

| 항목 | 방법 | 상태 |
|------|------|------|
| 키보드 전역 Tab | 헤더 → 탭 → 패널 → FAB | ✅ 지원 |
| ⌘/Ctrl+K 검색 | 포커스 · Escape 닫기 | ✅ |
| Board 화살표/Space DnD | 카드 포커스 후 ←/→ · Space | ✅ |

스크린 리더 매트릭스: macOS VoiceOver · Windows NVDA에서 주요 탭(일지/문서/일정/프로세스) 1회씩 통과를 권장.

## 스킵 · 랜드마크

- **본문으로 건너뛰기** — 첫 Tab에서 스킵 링크 (`#main-content`)
- `header` / `main` / `footer` landmark
- 주요 탭 목록: `aria-label="주요 패널"`
- 탭 전환 시 패널 내 첫 포커스 가능 요소로 이동

## 키보드 단축키

| 영역 | 키 | 동작 |
|------|-----|------|
| 전역 | Tab / Shift+Tab | 포커스 순회 |
| 전역 | ⌘/Ctrl+K | 통합 검색 포커스 |
| 검색 | ↑/↓ · Enter · Escape | 결과 이동 · 선택 · 닫기 |
| Journal 태그 | Enter | 태그 추가 |
| Journal 태그 | Backspace (입력 빈 상태) | 마지막 태그 삭제 |
| Docs 목록 | ↑/↓ | 문서 선택 |
| Board 카드 | ←/→ | 이전/다음 컬럼으로 이동 |
| Board | Space (dnd-kit) | 키보드 드래그 (KeyboardSensor) |
| 드롭다운/팀 패널 | Escape | 닫기 |

## 스크린 리더

- 아이콘 버튼에 `aria-label`
- Journal/Docs 저장: `aria-live` / `aria-busy`
- Docs 편집 모드: `aria-pressed`, 목록 `aria-current` / `aria-selected`
- 검색: `role="listbox"`, `aria-activedescendant`
- 저장 모드: `role="menu"` / `menuitemradio`
- 팀 사이드바: `role="dialog"` `aria-modal`

## 포커스 관리

- `useEscapeToClose` · `useFocusTrap` (`src/lib/a11y.ts`)

## 로딩 · 에러 · 빈 상태

- 저장 중 스피너 + `aria-busy`
- 실패 시 사용자 메시지 + **다시 시도**

## 모션

`prefers-reduced-motion: reduce` 시 애니메이션·트랜지션 축소 (`globals.css`)
