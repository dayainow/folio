### 스크린 리더 매트릭스 (수동)

| 환경 | 확인 포인트 | 통과 기준 |
|------|-------------|-----------|
| macOS VoiceOver | 스킵 링크 · 주요 패널 탭 · 저장 live · 온보딩 dialog | 랜드마크·이름·상태 읽힘 |
| Windows NVDA | 동일 + 고대비 토글 `aria-pressed` | 상태 변경 안내 |

### 포커스 · 대비

- `:focus-visible` — 2px ring (`globals.css`)
- `html.high-contrast` — 전경/배경/테두리 강화, 포커스 3px
- `announceToScreenReader` — `#folio-a11y-live` polite/assertive

## 스킵 · 랜드마크

- **본문으로 건너뛰기** — 첫 Tab에서 스킵 링크 (`#main-content`)
- `header` / `main` / `footer` landmark
- 주요 탭 목록: `aria-label="주요 패널"`
- 탭 전환 시 패널 내 첫 포커스 가능 요소로 이동

## 키보드 단축키

| 영역 | 키 | 동작 |
|------|-----|------|
| 전역 | Tab / Shift+Tab | 포커스 순회 |
| 전역 | ⌘/Ctrl+K | 통합 검색 포커스 |
| 검색 | ↑/↓ · Enter · Escape | 결과 이동 · 선택 · 닫기 |
| Journal 태그 | Enter | 태그 추가 |
| Journal 태그 | Backspace (입력 빈 상태) | 마지막 태그 삭제 |
| Docs 목록 | ↑/↓ | 문서 선택 |
| Board 카드 | ←/→ | 이전/다음 컬럼으로 이동 |
| Board | Space (dnd-kit) | 키보드 드래그 (KeyboardSensor) |
| 드롭다운/팀/온보딩 | Escape | 닫기 |

## 스크린 리더

- 아이콘 버튼에 `aria-label`
- Journal/Docs 저장: `aria-live` / `aria-busy`
- Docs 편집 모드: `aria-pressed`, 목록 `aria-current` / `aria-selected`
- 검색: `role="listbox"`, `aria-activedescendant`
- 저장 모드: `role="menu"` / `menuitemradio`
- 팀·온보딩·도움말: `role="dialog"` (+ `aria-modal` where applicable)
- 테마/고대비 전환: live region 안내

## 사용성 (P55)

- 첫 방문 **온보딩 투어** (`OnboardingTour`, `folio_onboarding_done_v1`)
- 사이드바 **도움말 팁** (`HelpTipsButton`)
- 사용자 친화 에러 (`friendlyErrorMessage` / `toUserErrorMessage`)
