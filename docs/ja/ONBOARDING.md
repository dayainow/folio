# Folio オンボーディング — 最初の10分

約 **10分** で Folio を使い始められます。

---

## 準備

- Node.js 20+
- リポジトリをクローン

```bash
cd /path/to/folio
npm install
npm run dev
```

`http://localhost:3000` を開きます。

---

## ステップ 1 — Folio を開く

1. `http://localhost:3000` にアクセス
2. **Folio** ロゴとタブ（**日誌 / ドキュメント / ボード / プロセス**）が表示されれば OK
3. 既定は **日誌** タブ

**ヒント:** モバイルは下部タブ。要約パネルはヘッダーから開きます。

---

## ステップ 2 — 言語

ヘッダーの言語切替（**ko / en / ja**）。ブラウザ言語を検出し、未対応時は韓国語にフォールバックします。
