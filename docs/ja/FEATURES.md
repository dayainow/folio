# Folio 機能

| 領域 | 概要 |
|------|------|
| **日誌** | 日次メモ · タグ · 自動保存 |
| **ドキュメント** | Markdown · カテゴリ · プレビュー |
| **ボード** | カンバン + Jira 同期 |
| **プロセス** | Beacon ゲート / タイムライン |
| **検索** | ⌘K + 高度なフィルター (P52) |
| **i18n** | 韓国語 / 英語 / 日本語 (P53) |
| **プラグイン** | マーケット · ウィジェット · カスタムフィールド |

アプリ内 **ガイド** と [SEARCH.md](./SEARCH.md) を参照。
