# Folio 온보딩 — 처음 10분

처음 보는 사람도 **10분 안에** Folio를 쓰기 시작할 수 있도록 단계별로 안내합니다.

> 스크린샷 placeholder: `(스크린샷: …)` 문구는 나중에 실제 이미지로 교체하면 됩니다.

---

## 시작 전

- Node.js 20+ 권장
- Folio 저장소를 클론해 둔 상태

```bash
cd /path/to/folio
npm install
npm run dev
```

브라우저에서 `http://localhost:3000` 을 엽니다.

---

## 1단계 — Folio 열기

1. 브라우저에서 `http://localhost:3000` 접속
2. 상단에 **Folio** 로고와 탭(**일지 / 문서 / 일정 / 프로세스**)이 보이면 정상입니다
3. 기본으로 **일지** 탭이 열려 있습니다 (글쓰기 우선 레이아웃)

`(스크린샷: 첫 화면 — 헤더 · 일지 에디터 · 우측 요약 사이드바)`

**팁:** 모바일에서는 하단 탭 네비로 패널을 전환하고, 우측 패널 버튼으로 요약을 엽니다.

---

## 2단계 — 저장 모드 선택

1. 우측 **요약** 사이드바 하단을 확인합니다  
   (좁은 화면이면 헤더의 패널 버튼을 눌러 시트를 엽니다)
2. **저장 모드** 토글을 찾습니다
3. 처음에는 **로컬(local)** 을 권장합니다 — 브라우저에만 저장되며 로그인 없이 바로 씁니다

| 모드 | 언제 쓰나 |
|------|-----------|
| **local** | 개인 사용, 오프라인, 가장 빠름 |
| **cloud** | 팀 공유 · 로그인(Supabase) 필요 |
| **beacon** | `.beacon` 프로젝트 상태와 연동할 때 |

`(스크린샷: 사이드바 하단 저장 모드 토글)`

자세한 차이는 [FEATURES.md — 저장 모드](./FEATURES.md#저장-모드)를 참고하세요.

---

## 3단계 — 첫 일지 작성

1. **일지** 탭이 선택돼 있는지 확인
2. 상단 날짜가 **오늘**인지 확인 (`‹ 날짜 ›` 로 이동 가능)
3. 큰 입력칸에 오늘 한 일을 적습니다  
   예: `Folio 온보딩 완료. 일지/문서/일정 흐름 확인.`
4. 우측 상단 **저장** 을 누르거나, 잠시 기다리면 **자동 저장**됩니다

`(스크린샷: 일지 입력 후 저장 버튼)`

**확인:** 우측 사이드바 **오늘의 일지** 미리보기에 내용이 반영되면 성공입니다.

---

## 4단계 — 태그 추가

1. 일지 카드 하단 **태그** 입력란을 찾습니다
2. 예: `onboarding` 입력 후 **Enter** (또는 쉼표)
3. 배지 `#onboarding` 이 붙는지 확인
4. 이미 쓴 태그가 있으면 제안 목록을 클릭해 추가할 수 있습니다

`(스크린샷: 태그 입력 · 배지 · 자동완성)`

**팁:** 태그는 나중에 검색·통계·필터에 쓰이므로 짧은 소문자 단어를 권장합니다.

---

## 5단계 — 문서 생성

1. 상단 탭에서 **문서** 클릭
2. 왼쪽 **새 문서** 버튼 클릭
3. 제목 예: `팀 온보딩 체크리스트`
4. 본문에 마크다운을 적습니다

```md
# 팀 온보딩 체크리스트

- [ ] Folio 로컬 실행
- [ ] 첫 일지 작성
- [ ] 일정에 태스크 추가
```

5. **저장** 후 목록에 나타나는지 확인

`(스크린샷: 문서 목록 · 에디터 · 저장)`

**다음으로 해볼 것:** 본문에 `[[다른 문서 제목]]` 을 쓰면 링크 그래프에 연결됩니다.  
→ [FEATURES.md — 문서](./FEATURES.md#문서-docs)

---

## 6단계 — 일정 생성

1. 상단 탭에서 **일정** 클릭
2. 칸반 컬럼(예: **Backlog**)의 **+** 버튼 클릭
3. 제목 예: `온보딩 가이드 읽기`
4. 저장하면 카드가 컬럼에 나타납니다
5. 카드를 **드래그**해 In Progress 등으로 옮겨 보세요

`(스크린샷: 칸반 · 새 카드 · 드래그)`

**확인:** 우측 사이드바 **진행 중 태스크** 숫자가 바뀌면 연동이 된 것입니다.

---

- [ ] 저장 모드가 local(또는 원하는 모드)
- [ ] 오늘 일지 1건 저장
- [ ] 태그 1개 이상
- [ ] 문서 1개 생성
- [ ] 일정 카드 1개 생성 · 이동
