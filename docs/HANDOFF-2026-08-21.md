# Folio 인수인계 — 2026-08-21

다음 담당자가 Folio 4.2.0의 제품 방향과 현재 구현 상태를 빠르게 파악하기 위한 문서다.

## 한 줄 정의

Folio는 기록, 문서, 할 일과 업무 흐름을 한곳에서 관리하는 **Local-first 개인 업무 비서**다.
가입이나 Beacon 설치 없이 시작하며, 클라우드·AI·Beacon은 필요할 때 연결하는 확장 기능이다.

### Beacon 선택형 확장 전환

- Beacon이 없어도 P0–P4 Gate, Timeline과 업무 흐름을 생성·편집·저장

- 로컬 사용 시 Beacon API와 상태 점검을 백그라운드에서 호출하지 않음
- 연결 실패 시 로컬 데이터 보존, 안전한 폴백, 재시도/로컬 확정 UX 제공

## 중요한 설계 결정

1. **제품은 하나, 기술은 모듈화**
   사용자는 Folio 하나만 설치한다. Beacon은 별도 제품처럼 요구하지 않고 고급 Provider로 연결한다.
2. **로컬이 항상 안전망**
   저장과 Provider 연결이 실패해도 사용자의 로컬 업무 데이터는 유지한다.
3. **선택 기능은 경고가 아니다**
   로컬 모드에서 Beacon 미연결을 시스템 장애로 표시하지 않는다.
4. **기존 데이터 호환**
   Beacon CLI 원본과 Folio 로컬 데이터는 서로 덮어쓰지 않는다.
5. **기능 추가보다 사용성 우선**
   다음 단계는 화면에 기능을 더 쌓기보다 실제 사용자 관찰과 마찰 제거를 우선한다.
